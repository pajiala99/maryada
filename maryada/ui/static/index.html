    About this demo

    What you are looking at, and what it does not do yet.

    Synthetic data

    Every call, lender, borrower, agent, complaint and case here is invented. The calls were written by us, voiced with Gnani's Timbre v3.0 and streamed through Gnani's Prisma v3.0. Names are written in Latin script in lists; transcripts keep the words as Prisma heard them.

    Limits

    • Timbre voices are cleaner than real people, so real calls will score lower.
    • Noise is mixed in digitally; there is no real handset, network jitter or packet loss.
    • Recordings are assumed to be stereo, one side per channel. A mono recording would need diarization, which Prisma's realtime API does not provide.
    • The LLM judge is a stand-in model on a free tier. Gnani's Evon v3.3 was not on the API yet, so it was not measured.
    • The RBI text was read through published summaries; clause numbers should be checked against the RBI's own document. This is an automated check, not legal advice.
    • Lines beyond Hinglish and Punjabi were written by us and not checked by native speakers.
    • There is no real login. The API runs in test mode, and the online demo replays saved runs; streaming live and speaking as the agent need the repository, a running server and a Gnani API key.

    Built by

    Hardik Pajiala and Khushi Dangi, Thapar Institute of Engineering and Technology, for Gnani.ai's Great Indian AI Internship challenge. Code and results on GitHub.
